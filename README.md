#  - UI/UX Design 

A comprehensive educational consultancy platform design connecting students with global education opportunities.

## 🎨 Design Overview

**Concept:** Multi-brand educational hub unifying Edvoy, IDP, EduConsult, Shorelight, and other consultancies under a cohesive interface.

**Target Users:** Students (Nepal-focused) seeking study abroad guidance, test prep (IELTS/GRE/GMAT/TOEFL), and admission consulting.

## ✨ Key UI Components

- **Card-based layout** – Modular course, university, and testimonial cards
- **Hero sections** – Bold CTAs ("Free Consultation," "Apply Online")
- **Pricing tables** – Tiered course enrollment with badges (Popular/Best Seller)
- **Event calendars** – Workshop and fair listings with registration
- **Testimonial sliders** – Student success stories with ratings
- **Footer navigation** – Multi-column with quick links and newsletter signup

## 🎯 UX Features

- **Clear conversion paths** → Browse → Consult → Apply
- **Trust indicators** → Success rates (90%+), student counts (500+), experience years
- **Filtering system** → Search courses by subject, university, destination
- **Booking workflow** → Schedule free consultation in 2-3 clicks

## 🎨 Design Tokens

| Element | Style |
|---------|-------|
| Primary CTAs | Blue (`#2563EB`) |
| Success badges | Green (`#10B981`) |
| Body text | Gray (`#4B5563`) |
| Cards | White + shadow, rounded corners |
| Spacing | 8/16/24/32px grid system |

## 📱 Responsive

- Mobile-first card grid
- Collapsible navigation for tablet/mobile
- Flexible typography scale
